# 输出格式参考

## 会议纪要格式

```markdown
# 会议纪要：<主题>

- **日期**：<从文件名或内容推断>
- **时长**：约XX分钟
- **形式**：<线上/线下>
- **参与方**：<从内容推断>
- **主题**：<核心主题>

---

## 一、<第一个议题>
...

## N、待跟进事项
| 事项 | 负责方 | 优先级 |
|---|---|---|
| ... | ... | ... |

## N+1、关键结论
1. ...
```

## 工作日报格式

```markdown
# 工作日报

- **日期**：
- **与会人员**：

---

## 一、项目现状
## 二、项目架构设计思路（如有）
## 三、当前关注点与需求
## 四、项目开发路径（如有）
## 五、待跟进事项
```
